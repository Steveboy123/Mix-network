How mixing works

Every app opens connections to websites. MixNet hands each new connection to one of your links: Wi-Fi, Ethernet, a phone over USB, and so on. Browsers, download managers, game launchers and cloud sync open many connections at once, so they get the combined speed of all your links. If a link drops, new connections move to the others within a few seconds.

A single connection, like one plain file download, still runs over one link. Splitting a single connection across links needs a bonding server on the internet to put the pieces back together (that's what paid services such as Speedify run).

Can't reach MixNet

The MixNet app isn't answering. Start it again with python -m mixnet; this page reconnects by itself.
